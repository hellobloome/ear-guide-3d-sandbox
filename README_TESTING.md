# Bloomé 3D Ear Beta 1B.3 — Four Locked Points

This is the current reusable 3D calibration sandbox.

## Locked points
1. Endocrine
2. Sympathetic
3. Subcortex
4. Thalamus

All four use Ear 1 and remain fixed while the ear rotates.

## How to inspect
- Drag to rotate.
- Pinch / scroll to zoom.
- Use the point-name buttons to center the camera near a locked point.
- Hide point labels if they overlap.
- Use the standard camera presets when useful.

## How to calibrate the next point
1. Click **Turn on placement mode**.
2. Rotate / zoom to the new point.
3. Tap the ear surface.
4. Copy the temporary Position + Normal.
5. Send that data and a screenshot to ChatGPT.
6. The temporary marker does not alter any locked point.
